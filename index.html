Pebble 0.3 language guide

say "Hello!" — print text or a value.

set score to 10 — create or update a variable.

add 5 to score — addition.

subtract 2 from score — subtraction.

multiply score by 2 — multiplication.

divide score by 2 — division.

ask name "Your name?" — request text input.

if score is greater than 10 — start a condition.

else and end — alternate branch and close a block.

repeat 3 times — repeat a block.

function greet and call greet — define and call a function.

show variables — list current variables.

clear — clear console output.

wait 500 — pause for 500 milliseconds.

help — display the quick command guide in the console.

# comment — a line beginning with # is ignored.

Comparisons: is equal to, is not equal to, is greater than, is less than, is at least, is at most.

Logic: use and, or, and not to combine or reverse conditions.
