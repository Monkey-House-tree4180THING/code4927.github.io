Pebble language guide

say "Hello!" — print a message.

set name to "Alex" — create a variable.

say name — print a variable's value.

set score to 10 — store a number.

add 5 to score — add to a variable.

subtract 2 from score — subtract from a variable.

repeat 3 times followed by commands and end — repeat commands.

Lines beginning with # are comments.
