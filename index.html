Language documentation

Variables: set score to 10. Values can be strings, numbers, or booleans.

Conditions: if score is equal to 10, is not equal to, is greater than, is less than, is at least, and is at most.

Logic: combine conditions with and or or. Use not before a condition.

Booleans: true and false.

Input: ask answer "What is 2 + 2?" stores the response as text.

Functions: create a function using function greet, put commands below it, and close it with end. Run it using call greet. Functions in this version take no parameters and return no value.

Loops: repeat 3 times executes its block three times. Loops can be nested.

Arithmetic: addition, subtraction, multiplication, and division require numeric values. Division by zero is an error.
